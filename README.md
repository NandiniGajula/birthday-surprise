# birthday-surprise
Birthday surprise website
BUJJI BIRTHDAY SURPRISE WEBSITE 💙

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html. It should open in Chrome, Edge, or another browser.
   Internet is needed for the decorative Google Fonts; the website itself works offline.

PASSCODE
- The starter passcode is 1234.
- To change it, open script.js in Notepad or VS Code.
- Find: const PASSCODE = "1234";
- Replace 1234 with your own 4-digit code and save.



CUSTOMIZATION
- Edit the words in index.html.
- Change colours and layout in style.css.
- Change the passcode in script.js.
- Use your own photos and song through the on-page upload controls.
